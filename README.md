# electrosim.github.io

Тренажёр запускается через `index.html`.

Для переноса или публикации нужны `index.html`, `app.js`, `styles.css`,
папки `assets` и `presets`. Однофайловая копия больше не используется.
Папка `tools` содержит проверки и обновление каталога; при запуске сайта
она не загружается.

Файлы сохранений лежат в `presets`. Схемы из подготовленного `presets/catalog.js`
появляются в меню автоматически. Для автоматического чтения новых файлов при
локальном запуске подключите папку через кнопку «Подключить папку presets».
Выбор папки запоминается; иногда браузер просит снова разрешить чтение.
В меню «Схемы» кнопка «Сохранить схему в файл» скачивает текущую работу
в формате `.ad-scheme.json`, включая протокол. Кнопка «Открыть схему из файла»
сразу загружает выбранное сохранение. Для файлов с несколькими схемами
появляется группа «Из открытого файла»: выберите нужную и нажмите «Открыть
выбранную схему». Старые сохранения браузера доступны в отдельной группе списка.

«Новая схема» возвращает начальный щит с двумя DIN-рейками. Перед заменой
несохранённой работы появляется предложение сохранить её в файл либо отменить
действие. Тренажёр автоматически сохраняет последнюю работу в этом браузере
каждые две секунды; при следующем запуске предлагает восстановление.
Автосохранение не переносится на другое устройство: для этого нужен файл.

Перед публикацией новых JSON-схем обновите каталог: `node tools/update-presets.js`.
Подробности — в `presets/README.txt`.

## Управление

Лоток деталей разделён на категории: монтаж и соединения, защита, управление,
привод, освещение и розетки, бытовые приборы, измерения. Категории раскрываются
независимо; их состояние запоминается в этом браузере. Поиск по названию или
обозначению показывает детали из всех категорий. После очистки поиска
возвращается прежнее раскрытие категорий. Есть кнопки сворачивания и
разворачивания всех разделов. Перетаскивание и кнопка размещения на тачскрине
работают с карточками внутри категорий.

На компьютере колесо мыши изменяет масштаб, зажатое колесо перемещает рабочее
поле, а правая кнопка открывает контекстные меню.

В настройках «Провод» выбирается сечение отдельного медного провода
от 0,5 до 35 мм². Для уже проложенного провода выбор доступен по правому
клику в пункте «Сечение». Параметр сохраняется вместе со схемой.
Источники и текущие границы модели: [WIRE-SECTIONS.md](WIRE-SECTIONS.md).

На телефоне и планшете перенос рабочего поля выполняется одним пальцем
по свободному месту или закреплённому щиту, масштаб меняется двумя пальцами.
После отпускания одного пальца перенос плавно продолжается оставшимся.
Меню «Провод» находится слева вверху; отмена появляется в нём только при
прокладке провода или выборе места для детали. Долгое нажатие открывает
меню объекта или провода. Деталь можно перетащить за её изображение либо нажать
`+` в лотке, а затем коснуться места установки.

## Проверка проекта

Последовательно соединённые нагрузки делят напряжение пропорционально
эквивалентным сопротивлениям. Расчёт работает также для смешанных цепей;
мультиметр, токовые клещи и счётчик используют полученные напряжения и токи.
Формулы, пример и границы модели: [VOLTAGE-DIVIDER.md](VOLTAGE-DIVIDER.md).

Все проверки расчётов, защит, мультиметра, управления и сохранений запускаются
без браузера одной командой: `node tools/check.js`. Нужен Node.js.

Результаты анализа и оптимизации: [AUDIT.md](AUDIT.md).

При сенсорном подключении проводов и переносе щупов появляется лупа с увеличением 2,5×. Она показывает конец провода или остриё щупа, работает также на сенсорном ноутбуке и скрывается при отпускании пальца, отмене и масштабировании двумя пальцами. Управление мышью не включает лупу.

Рабочее поле на компьютере и мобильных устройствах — 2480 × 3100 условных единиц (в четыре раза больше по площади). Начальное окно остаётся 1240 × 1550: размеры объектов при запуске сохранены. Поле можно перемещать вправо и вниз, а предел отдаления позволяет увидеть расширенную сцену.

Кнопки ↶ и ↷ снизу слева отменяют и повторяют до пяти последних изменений схемы. На компьютере доступны Ctrl+Z, Ctrl+Y и Ctrl+Shift+Z. Один перенос считается одним действием; масштаб и перемещение поля не учитываются. Новое изменение очищает ветку повторения, открытие другой схемы сбрасывает историю. История действует в текущем сеансе.
