СХЕМЫ ИЗ ПАПКИ PRESETS

Помещайте сюда файлы .ad-scheme.json или .json, экспортированные из тренажёра.
Поддерживаются отдельные схемы и файл «Экспорт всех», содержащий несколько схем.
Откройте index.html. Схемы из каталога сразу появятся в разделе «Схемы» →
«Готовые схемы». Открывать их из файла по одной не нужно.

АВТОМАТИЧЕСКОЕ ЧТЕНИЕ НОВЫХ ФАЙЛОВ

Для локальной работы раскройте пункт «Папка схем на этом компьютере»
и нажмите «Подключить папку presets», затем
выберите эту папку. Можно выбрать папку всего проекта: тренажёр найдёт presets.
Chrome/Edge попросят разрешить чтение папки. После подключения список сам
обновляется при открытии меню схем, возвращении в окно и каждые 15 секунд.
Добавленные и изменённые файлы появляются автоматически, удалённые исчезают.
Выбранная папка запоминается. Если браузер снова запросит доступ, нажмите
«Разрешить доступ к папке presets».

Файлы в этой папке читаются, но не изменяются тренажёром. Кнопка «Сохранить
схему в файл» скачивает текущую работу на компьютер пользователя. Чтобы
добавить её в библиотеку сайта, поместите полученный файл сюда и обновите
каталог. «Открыть схему из файла» загружает пользовательскую работу напрямую.
На хостинг пользовательские работы автоматически не отправляются.

КАТАЛОГ ДЛЯ ДРУГОГО КОМПЬЮТЕРА И СТАТИЧЕСКОГО САЙТА

catalog.js — автоматически созданная копия содержимого JSON-файлов, благодаря
которой index.html показывает подготовленные схемы без запроса доступа к папке.
Перед переносом нового набора схем или публикацией сайта обновите каталог:

    node tools/update-presets.js

Команду выполняют из папки проекта; для неё нужен Node.js. catalog.js не нужно
редактировать вручную. Источником схем остаются JSON-файлы.

Браузер без поддержки подключения папок показывает схемы из catalog.js;
для своей работы используйте «Открыть схему из файла» и «Сохранить схему в файл».
